# 输出格式

命令的输出只有三种：`text`（默认，终端可读）、`markdown`（表格，贴文档用）、
`json`（给脚本和 agent）。`-f` 也收 `md` / `table` 两个别名。

```bash
prism quote 600519                  # text
prism quote 600519 -f markdown      # markdown 表格
prism quote 600519 -f json          # JSON
prism quote 600519 -f json -o out.json   # 落盘
prism quote 600519 -o -                  # 显式写标准输出
prism quote 600519 -o ~/data/            # 给目录 → prism-stock-20261026-093012.txt
```

落盘时会在 stderr 打一行 `saved: <路径> (bytes, format=…)`，stdout 仍然干净 ——
管道里不会混进提示。`-o` 给目录时文件名带时间戳，不会互相覆盖。

**格式只看 `-f`，扩展名不推断**：`-o out.json` 但你没写 `-f json`，写进去的就是
text。要 JSON 就两个都写。

## JSON 信封

所有 `-f json` 至少有三个键，表格型数据统一放 `rows`：

| 键 | 何时出现 | 含义 |
| --- | --- | --- |
| `ok` | 总是 | 这次动作整体是否成功 |
| `source` | 多数 | 数据来自哪个源（`tencent` / `xueqiu` / `akshare` / `baostock` …） |
| `as_of` | 有数据日的动作 | 数据日（`20261023` / `2026-10-26`） |
| `count` | 表格型 | 行数 |
| `rows` | 表格型 | 行数组 |
| `data` | 单对象 | 非表格载荷（如财务三表的结构化结果） |
| `note` | 有时 | 降级、口径、不可用原因等说明 |

信封是**加法**：各命令原有的键（`date` / `title` / `items` / `source`…）一个都不删，
只在缺标准键时补上。所以老脚本读 `out['rows']` 照常可用；唯一形状变化是
原本顶层直接是数组的命令（`quote` 等）现在外面套了一层对象。

实测：

```json
{"ok": true, "count": 1, "rows": [{"input": "600519", "symbol": "sh600519",
 "ok": true, "源": "tencent", "name": "贵州茅台", "现价": 1335.0, …}]}
```

**行级 `ok` 比命令级更细。** 批量取数时个别代码失败不影响整条命令：

```json
{"ok": true, "count": 1, "rows": [{"input": "999999", "ok": false,
 "err": "无返回（代码错误 / 停牌 / 指数别名未覆盖）"}]}
```

这条命令退出码是 0 —— 请求完成了，只是那只票没数据。真要看整体失败，看有没有
抛错（见下）。

### 回到旧形状

`PRISM_JSON_LEGACY=1` 可临时关掉信封，恢复改造前的原始形态，给还没改完的老脚本用：

```bash
PRISM_JSON_LEGACY=1 prism quote 600519 -f json     # 顶层直接是数组
```

## 退出码

| 码 | 含义 |
| --- | --- |
| 0 | 成功 |
| 1 | 取数失败（数据源报错 / 无数据 / 上游结构变化） |
| 2 | 用法错误（缺参数、参数冲突、命令不存在） |
| 3 | 证书校验失败 |

用错参数当场退 2 并给出正确写法，不打印堆栈：

```
$ prism kline
error: kline 需要股票代码: prism kline 600519 [--bars 120]
```

取数失败退 1，错误信息带源名，`PRISM_DEBUG=1` 才打堆栈。

## 错误语义

三条硬约束，写在 `stock/error.py` 里：

- **数据源失败 ≠ 没数据。** 失败一律显式带原因，不静默返回空表。
- 接口返回 0 / 空不当作正常值，由各桥透传状态。
- 北向资金不可用时显式标注，不填 0。

## 文本与表格

`text` 是给人看的：单股动作给一行摘要，表格动作对齐成列，超宽字段截断加省略号。
`markdown` 输出标准表格，可直接拼进报告：

```markdown
## 实时行情

| 代码 | 名称 | 现价 | 涨跌幅% | 换手% | 量比 | 流通市值亿 | PE动 | PB |
|---|---|---|---|---|---|---|---|---|
| 600519 | 贵州茅台 | 1335.0 | 1.25 | 0.46 | 1.53 | 16688.59 | 20.49 | 6.64 |
```

少数动作有自己的原生格式（`diagram` 出 mermaid、`excel` 出 xlsx、`kline --chart`
出 SVG），此时 `-f` 仍作用于随附的说明文本，图/表文件走各自的选项。
